# Changelog

## 0.2.0 - Revision implementation alignment

### Method implementation

- Added provenance-linked, bounded non-adjacent cross-window RMG associations
  using activated history only; these links do not assert causal truth.
- Added typed claim/window/version-bound feedback, persistent receipts,
  idempotency, transactional rollback, and separate final acceptance.
- Integrated targeted Investigator checks, fresh Steward synthesis, snapshot
  persistence, and evidence-grounded report regeneration into the local API/UI.
- Added explicit offline typed-evidence execution and labelled historical
  fixed-score feedback controls.
- Added paired-feedback evaluation with common frozen T0, separate private
  labels, exact acceptance counting, and distinct success/capped-cost metrics.
- Added portable, documented RCACopilot and RCAgent adaptations.
- Added one-second feature configuration and multi-interval 60-second window
  export without modifying or relabelling historical checkpoints.

### Repository maintenance

- Rewrote the README with setup, current mechanism-to-source mapping,
  evaluation entry points, historical/current boundaries, and provenance links.
- Updated system architecture/validation, baseline documentation, result
  provenance, and release checklist; refreshed integrity audit outputs.
- Added self-contained protocol, API, cross-window, and documentation checks.
- Preserved original source snapshots, historical configurations, archived
  result transcription, raw-workspace exclusions, and unrelated repository data.

### Experimental boundary

No training, paid-model evaluation, dataset download, or new human study is
part of this update. Manuscript result rows are transcriptions, not new run
logs. Baseline backbone/model parity, one-second trained weights, and matching
revised-method execution manifests remain to be established. See
[revision notes](docs/REVISION2_ALIGNMENT.md).

# TORAI source snapshot

Official replication package: <https://figshare.com/articles/software/31938495>

This directory is a compact convenience snapshot of the implementation used by
the Root-Teller evaluation adapter. It intentionally omits upstream datasets,
notebooks, CI files, and generated outputs. Consult the official replication
package for the complete distribution and setup documentation.
